# bridge-hotel

Bridge Hotel

    Description

this is a simple website that enables the user to recieve his/her meals by just clicking the order now button for the meal he/she wants.

---

    Live URL

 https://stanleykiboi.github.io/bridge-hotel/

---

    Objective

- To display the vareity of food we offer
- To enable the user get the meal he want by clicking the order now button

---

    Technology used

- HTML (for web structure)
- CSS (for designing the page)
- Javascript (for logic and functionality)

---

    How It Works

- user get to select the meal he/she wants
- After identifying it he may click the order now button
- To select the method of payment
